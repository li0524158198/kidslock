Android 手机 / 平板 / 电视

本机

下载后直接安装，无需注册。支持 Android 5.0 及以上，通用安装包覆盖全部架构。

⬇ 下载安装（APK · 4.5MB） 版本 1.3 · 新增 30 秒测试档 · 权限最小化
安装步骤
  1. 点击上方按钮下载安装包
  2. 下载完成后点击通知栏或文件管理中的 apk
  3. 若提示「禁止安装」：设置 → 应用 → 浏览器 → 允许安装未知应用
  4. 安装完成，桌面打开「儿童锁屏」
📺 小米电视等 Android TV 也可安装：将 apk 拷入 U 盘，用电视「高清播放器」打开安装。

鸿蒙 HarmonyOS

本机

HarmonyOS 4.x 及更早版本：系统兼容安卓应用，直接用上方 APK 按钮安装即可。

HarmonyOS NEXT 5.0+（纯血鸿蒙）：系统仅允许应用市场或开发者签名安装，暂不支持浏览器直装。可选方式： ① 华为应用市场上架后搜索安装（推荐正式分发）；② 开发者使用 DevEco Studio 安装。

⬇ 鸿蒙安装包（HAP · 161KB · 需签名） 供开发者经 DevEco Studio 签名后安装

iPhone / iPad

本机

苹果系统政策限制，App 必须通过 App Store 或 TestFlight 分发，无法从浏览器直接安装。

获取方式
  1. 上架 App Store：使用已构建的 SwiftUI 工程 + 苹果开发者账号（$99/年）
  2. 内测分发：TestFlight 邀请链接安装（需付费开发者账号）
  3. 个人自装：Mac + Xcode 免费证书签名，7 天有效期
