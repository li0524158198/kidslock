# 儿童锁屏下载站 · 服务器部署说明（Python 版）

零依赖：服务器只需要 Python 3.6+（CentOS/Ubuntu 系统自带），无需 pip 安装任何东西。

## 一、上传解压

把 `kidslock-download-site.zip` 上传到服务器（scp / sftp / 宝塔面板均可）：

```bash
# 本机执行（把 your-server 换成你的服务器，路径按需调整）
scp kidslock-download-site.zip root@your-server:/opt/

# 服务器上执行
cd /opt && unzip kidslock-download-site.zip
# 得到 /opt/kidslock-download/（内含 server.py index.html assets/）
```

## 二、启动（两种方式任选）

### 方式 A：临时运行（先跑起来看看）

```bash
cd /opt/kidslock-download
python3 server.py --port 8080
# 看到「儿童锁屏下载站已启动」即成功
# 浏览器访问 http://服务器IP:8080/
```

### 方式 B：systemd 常驻（推荐，开机自启 + 崩溃自动拉起）

```bash
cp /opt/kidslock-download/kidslock-download.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now kidslock-download
systemctl status kidslock-download      # 查看状态
journalctl -u kidslock-download -f      # 实时看访问日志
```

## 三、放行端口

```bash
# 服务器防火墙（firewalld）
firewall-cmd --permanent --add-port=8080/tcp && firewall-cmd --reload

# 云厂商安全组：也要放行 8080/TCP（阿里云/腾讯云控制台操作）
```

## 四、验证

手机浏览器打开 `http://服务器IP:8080/`：
- 页面正常显示三个平台卡片
- 点「下载安装」→ 浏览器下载 apk → 下载完点击即可安装
- 服务器上 `tail -f /var/log/kidslock-download.log` 能看到每次下载记录

## 常用命令

```bash
python3 server.py --port 80           # 用 80 端口（客户访问不用带端口号）
python3 server.py --host 127.0.0.1    # 只监听本机（前面套 nginx 反代时用）
systemctl restart kidslock-download   # 改配置后重启
```

## 建议

1. **绑定域名 + HTTPS**：微信内打开 http 链接可能拦截下载，浏览器/扫码不受影响。有域名的话
   建议用 nginx 反代 + Let's Encrypt 免费证书：
   ```nginx
   server {
       listen 80;
       server_name download.你的域名.com;
       location / { proxy_pass http://127.0.0.1:8080; }
   }
   ```
2. **下载量统计**：`grep kidslock-v /var/log/kidslock-download.log | wc -l` 即 APK 下载次数
3. **发新版**：替换 `assets/` 内 APK（带版本号命名，如 kidslock-v1.5.1.apk，删除旧版本文件并同步改 index.html 按钮）与 HAP，然后重新打包 `dist/kidslock-download-site.zip`；建议发版前运行 `python tools/release_check.py` 核对产物与源码一致

## 安全说明（已内置）

- APK/HAP 走正确的 MIME + `Content-Disposition` 附件下载头
- 路径穿越攻击（`../`）一律返回 404
- server.py 本身不可被下载
- 多线程并发，多个客户同时下载互不影响
